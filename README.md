# Научился — демо

Тренажёр подготовки к ОГЭ по шести предметам: математика, физика, информатика, русский язык, история, обществознание.
По каждому предмету — диагностика навыков на 20 минут, тренажёр на 6 ключевых навыков и атлас навыков с привязкой к заданиям ОГЭ.
Открыть: https://4ern0kniznik.github.io/porog-demo/

Репозиторий содержит только собранную страницу демо. Исходники продукта не публикуются.
